See which Amazon ads actually lift organic rank — and which ones just pay rent.

amz-adlift is a local-first Python package, CLI, and MCP server that joins your exported Seller Central Search Query Performance (SQP), Amazon Ads Search Term, and keyword rank files to separate pure organic demand from incremental PPC lift. No OAuth, no cloud uploads.

pip install amz-adlift

What you get

Built for Amazon brand operators, PPC managers, agencies, and AI coding agents who want auditable numbers instead of Average-ACoS guesswork.

Stop paying ad rent on #1 organic terms

Subtracts Ads clicks and orders from weekly SQP totals to expose pure organic conversion rates and flag keywords where Exact PPC is just cannibalizing clicks you already own.

Spot real paid-to-organic rank leverage

Classifies every (asin, search_query) into four deterministic quadrants using rank velocity slopes and lagged paid-to-organic correlations instead of raw Average ACoS.

Zero OAuth, 100% local privacy

Runs directly on your exported CSV and XLSX reports. No SP-API credentials, no Ads API tokens, and no third-party SaaS ingesting your Seller Central data.

Parses real, messy Seller Central exports

Auto-detects SQP ASIN View and Brand View banners, Legacy Sponsored Products, 2026 Unified Reporting, native .xlsx Search Term files, and US/UK or EU/DE number formats.

Client-ready HTML/PDF reports in one command

Generates self-contained white-label audit decks with interactive 4-quadrant charts and print-to-PDF styling for agency reviews and CFO sign-off.

Native MCP server & skills.sh integration

Connect directly to Claude Desktop or Cursor over local stdio, or install the agent skill with npx skills add flovv/amz-adlift for guided audits.

Real workflows & code examples

Use amz-adlift from your terminal, wire it into Claude Desktop or Cursor via MCP, import it in Python notebooks, or install the agent skill.

Run a full paid-vs-organic audit, render a client-ready HTML/PDF deck, or export an upload-ready Amazon Ads bulksheet from local files.

# 1. Audit exported Seller Central SQP, Ads, and Rank CSV/XLSX files
amz-adlift audit \
  --sqp ./exports/US_Search_Query_Performance_ASIN.csv \
  --ads ./exports/Sponsored_Products_Search_Term_Report.xlsx \
  --rank ./exports/Helium10_Keyword_Tracker.csv \
  --category supplements \
  --margin 0.38 \
  --out ./reports/adlift_audit.json

# 2. Generate a white-label HTML/PDF executive audit report
amz-adlift report \
  --out ./reports/client_audit.html \
  --agency-name "Apex Marketplace Partners" \
  --client-name "SleepWell Naturals"

# 3. Generate privacy-safe AMC Clean Room SQL (HAVING COUNT(DISTINCT user_id) >= 100)
amz-adlift amc sql --days 28

# 4. Pro: Reallocate weekly budget & export Seller Central Bulk .xlsx with bid guardrails
amz-adlift allocate --budget 1100
amz-adlift bulksheet \
  --existing-bulk ./exports/Amazon_Ads_Bulk_Operations.xlsx \
  --out ./reports/upload_ready_bulk_update.xlsx \
  --max-change 0.25 --min-bid 0.20 --max-bid 8.00

Integrate funnel decomposition and 4-quadrant classification directly into notebooks, scheduled jobs, or agency pipelines.

from amz_adlift import ingest_and_align, classify_panel, enrich_with_pro_elasticity

# 1. Normalize & align SQP, Ads (CSV or XLSX), and Rank logs to SQP weekly buckets
panel = ingest_and_align(
    sqp_csv_path="tests/fixtures/sqp_multiweek.csv",
    ads_csv_path="tests/fixtures/ads_multiweek.csv",
    rank_csv_path="tests/fixtures/rank_multiweek.csv",
)

# 2. Classify every (asin, search_query) with >= 4 aligned weeks
diagnostics = classify_panel(panel, category="supplements", strict=True)
for d in diagnostics:
    print(f"{d.search_query:32s} {d.quadrant:22s} {d.diagnostic_summary}")

# 3. Optional: attach Pro rank elasticities & Halo Break-Even ACoS if licensed
pro_metrics = enrich_with_pro_elasticity(panel, category="supplements", product_margin=0.38)

Supported exports & funnel math

Every parser normalizes US/UK (1,234.56, $, £) and EU/DE (1.234,56, €) numbers and aligns dates to Amazon SQP Sunday–Saturday weeks.

Export Source Accepted Formats Handled Variations
Brand Analytics SQP .csv (single file or directory of weekly exports) Row 1 metadata banners (ASIN=[...], Select Week=[...]), ASIN View and Brand View counts
Amazon Ads Search Term .csv and native Seller Central .xlsx Legacy Sponsored Products, 2026 Unified Reporting (Total cost, Purchases), and German/EU headers
Keyword Rank Tracker .csv Helium 10 Keyword Tracker, DataDive, Perpetua, or generic Keyword, Date, Organic Rank logs
Amazon Ads Bulksheet .xlsx Reads exact numeric Campaign ID, Ad Group ID, Keyword ID, and live bids for safe Operation = Update writes
Quadrant Deterministic Criteria (≥ 4 aligned weeks) Recommended Action
CANNIBALIZED_RENT 4w median organic rank ≤ 2.5, pure organic CVR ≥ 12%, weekly spend ≥ $50 (or top 25%). Step down Exact CPC bids 15%–25% to stop paying rent on organic clicks.
FLYWHEEL_LEVERAGE Rank slope ≤ -0.5 pos/wk (climbing) and lagged paid-to-organic correlation ρ ≥ 0.35. Scale bids up to Halo-Adjusted Break-Even ACoS (margin × organic halo multiplier).
TREADMILL_DEAD_WEIGHT 4w spend ≥ $100, rank stagnant worse than #10, and SQP CVR < 50% of category median. Cut bids 25%–50% or negate until listing CVR and offer are fixed.
AT_RISK_DECAY Rank slope ≥ +0.75 pos/wk (slipping) with declining SQP Brand Click Share. Simulate bid cuts and deploy defensive Sponsored Products bids where halo is positive.
